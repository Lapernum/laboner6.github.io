FIRST RUN / 首次配置

连接你的图片仓库

图片本体上传到 Backblaze B2，作品索引 ImageInfo.json 提交到 GitHub。密钥只保存在本机的 admin/config.json，不会进入网站或仓库。

存储路径与 Git 选项
B2 密钥权限：创建 Application Key 时勾选 listBuckets 与 writeFiles，并限制到图片 bucket。公开读取由 Cloudflare / B2 公开 bucket 负责，不需要把密钥给前端。

工作流

  1. 拖入照片自动读取 EXIF 拍摄时间、尺寸，并在浏览器里生成缩略图。
  2. 自动上传原图与缩略图进入 B2，ID 接续 Star_Citizen_XXXXX。
  3. 自动排版按原来的算法重算 Flow / Num / Position，两行保持平衡。
  4. 一键发布提交 ImageInfo.json 并 push，GitHub Pages 自动更新。

本地预览模式会把图片写到 admin/media/，只用于试排版，不会部署。

把新照片拖进来

支持 JPG / PNG / WebP / AVIF，可多选或直接粘贴。会自动读取拍摄时间与尺寸。
